# Current capability audit

One row per workflow Wire Studio offers, **generated from the engine** (`npm run docs`;
`npm test` fails if this file is out of date). It answers, for every family × task: which
function builds it, what it needs (taken from the workflow's own requirement checks, the same
ones Setup and the run guard use), how the UI exposes it, which tests cover it, and which
exported file shows it.

How each column was established — documentation was not trusted on its own:

| Column | Source of truth |
|---|---|
| Implementation | the `build()` function of the task in `engine/families/<family>.mjs` |
| Status / evidence / verified | the task's own declaration, audited against the official templates, the node source code and the live validation (see [WORKFLOW_IMPLEMENTATION_AUDIT.md](WORKFLOW_IMPLEMENTATION_AUDIT.md)) |
| Required nodes / models / add-ons | `needs()` of the task run against an empty ComfyUI (`requirements()` in `engine/index.mjs`) |
| UI | the task group in `engine/catalog.mjs` and the badge the form schema sends to the browser |
| Tests | every workflow is built and family-checked (`tests/engine.test.mjs`) and validated against real node definitions (`tests/live.test.mjs`); named tests are counted from the test files |
| Export | the generated file in `workflows/` (kept equal to the engine output by `tests/export.test.mjs`) |
| Live ComfyUI | every row was accepted by ComfyUI 0.38.0's own validator (`npm run validate:live`); "graph only" means not yet run on a GPU |
